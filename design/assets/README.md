Files for the developer. `site-tokens.css` declares every token as a CSS custom property with light and dark values (OS setting by default, `data-theme` on `<html>` to override). `site.css` is the component and layout CSS; add `class="ofs-page"` to `<body>`. `tokens.dtcg.json` is the same tokens in the W3C Design Tokens format: light value in `$value`, dark value in `$extensions.mode.dark`. All three come from one source and agree.
